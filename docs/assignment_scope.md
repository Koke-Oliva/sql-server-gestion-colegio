# Alcance de la evaluación original

## Fuente revisada

Se revisó la pauta original de la **Prueba 2: Creación de Tablas y Consultas**, correspondiente al curso **Manejo de queries para la extracción y análisis de datos con SQL** de Educación Continua UC.

## Qué pedía la prueba

La evaluación solicitaba:

1. crear la base de datos `Colegio`;
2. crear las tablas usando la estructura indicada en un Excel adjunto;
3. implementar las relaciones siguiendo un diagrama proporcionado;
4. poblar las tablas con `Datos_Tablas.sql`, archivo proporcionado por el curso y que no requería cambios;
5. desarrollar las consultas especificadas en `Consultas.txt`.

Las ponderaciones eran:

| Componente | Ponderación |
|---|---:|
| Creación de tablas | 20% |
| Relaciones | 5% |
| Poblado | 5% |
| Consultas | 70% |

## Distinción de autoría

### Trabajo implementado por el estudiante

- creación de la base de datos;
- implementación de las tablas a partir de la especificación;
- implementación de claves primarias y foráneas;
- integración y ejecución del script de carga;
- desarrollo de las consultas requeridas.

### Material proporcionado por el curso

- estructura de tablas;
- diagrama de relaciones;
- dataset ficticio para poblar las tablas;
- requerimientos de las consultas.

Los datos personales aparentes presentes en el dataset corresponden a **personas ficticias**, por lo que se conservan en la versión de portafolio para mantener fidelidad y reproducibilidad.

## Criterio de presentación

El repositorio evita atribuir como diseño propio aquello que fue proporcionado por la evaluación. A la vez, conserva la entrega académica original y separa las mejoras posteriores de documentación, reproducibilidad y calidad de datos.
